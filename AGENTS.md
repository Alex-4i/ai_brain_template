# AGENTS.md — правила для любого ИИ, который читает эту папку

Прочитай этот файл и `_ИНДЕКС.md`, прежде чем отвечать. Если нужного файла нет в индексе, скажи об этом, а не выдумывай.

## Как отвечать
- Язык: русский.
- Стиль: коротко, по делу, без вступлений и комплиментов.
- Если не хватает данных, сначала задай уточняющие вопросы (не больше трёх).
- Не придумывай факты, цифры и источники. Если не знаешь, так и скажи.
- В конце длинного ответа дай краткий вывод в 1–2 строки.

## Как работать с контекстом
- Сначала читай `01_Я.md` и `02_Работа.md`.
- Для конкретной задачи ищи файл в `03_Проекты/`.
- Если для задачи есть готовый запрос в `04_Промты/`, используй его как основу.
- Перед рекомендациями проверь `06_Журнал.md`: не предлагай то, что уже решено иначе.

## Данные
- Соблюдай `05_Правила_данных.md`.
- Не повторяй в ответах персональные данные, пароли и ключи, даже если они случайно попали в контекст.

## Как обновлять память
- Если в разговоре появилось важное решение, предложи добавить строку в `06_Журнал.md` (дата, решение, причина).
- Не меняй файлы без моего подтверждения.
